# hasoftware-template - criando micro saas

Plataforma web com landing page institucional e área restrita.

## Tecnologias
- PHP 8
- MySQL
- MVC simplificado

## Estrutura

app/
  views/
  auth/

public/
  index.php

config/
routes/

## Funcionalidades

- Landing page
- Login de usuários
- Área restrita
    - dashboard
    - configuraao de imagens e texto da landing page
    - visualizacao de emailse
    - configuracao de api
